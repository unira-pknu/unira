# 평가 기준점

실제 전체 평가가 완료된 뒤 `python -m eval.tools.record_baseline`으로 생성한 기준점 JSON을 보관합니다.
실행 절차·지표 분모·출처 캡처 범위는 [기준점 문서](../../docs/evaluation/BASELINES.md)를 참고하세요.

현재 측정 결과를 임의로 채우지 않습니다. 이 디렉터리가 비어 있거나 README만 있으면 측정된 기준점이 아직 없는 상태입니다.

2026-11-10 최종 기록은 [measured_final_v2](baseline_20261110_034945.measured_final_v2.json)입니다.
같은 실행의 `measured_mixed_v2`는 마지막 시점 판정 검토 전 중간 기록입니다.
자동 채점과 Codex 로컬 검토를 합친 방법·분모·재현 한계는 [측정 보고서](../../docs/evaluation/QUALITY_MEASUREMENT_20261110.md)에 명시합니다.
